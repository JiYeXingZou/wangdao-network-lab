# 王道计网骚图 · 交互式协议动画

将传统的纸上网络拓扑和分层封装笔记，变成可以逐帧推演的交互式网页。

## 已实现（v0.2 原型）

- 从既有网页版保留 **11 个场景、70 个演示步骤**，包含 DHCP、ARP、跨网段转发、NAT、DNS、TCP/HTTP、IP 分片、封装、CSMA/CA。
- 全新浅色、教材式界面；可搜索章节、单步回退、自动播放、调速、复制定位步骤链接。
- **王道骚图无笔记原图作默认底图**：沿用旧版节点位置，在原图之上叠加可交互的广播、请求及回复路径；不再使用机器重绘的拓扑。
- **按需显示的逐层封装视图**：仅在真实报文发送/封装步骤显示报文；查表、状态变化、等待和复盘不占用报文区域。点击协议层展开字段。
- DHCP Discover 和 Request 的源/目的 IP、MAC、UDP 端口明确展示；OFFER/ACK 未确认的 IP 字段不编造；ARP 使用 Ethernet → ARP，两层结构。
- 可**导入自己的手写笔记图**临时替换主画布。原始无笔记底图已内置，默认无需上传。
- 自动化数据校验和 GitHub Actions。

### 如何运行

无需安装依赖，任选：

1. 直接双击仓库根目录的 `preview.html`，这是离线单文件版本。
2. 本地服务：`python3 -m http.server 8000`，打开 `http://localhost:8000/`。
3. GitHub Pages：在 Settings → Pages 选择 GitHub Actions，main 分支更新后自动校验并发布。自定义域名配置见 [DEPLOY.md](DEPLOY.md)。计划域名 `408.sagiri.top`；配置完成前不代表已上线。

```bash
npm test       # 使用 Node >=20 的内置测试器
npm run check  # JS 语法检查 + 测试
```

## 现阶段的边界（请在公开发布前阅读）

这是一版**可以运行的交互式原型，而非完整的网络仿真器**。旧版场景数据保留了教学简化假设；目前 DHCP、ARP、逐层封装和 TCP 等确有报文的核心步骤具有逐层可视化，其余部分保留原始字段与表项，**不会为缺失的信息伪造完整报文**。未来可以逐个补齐严格的报文数据模型和真题规则。

此版本默认显示用户原项目中已有的王道无笔记底图，位于 `assets/wangdao-original-clean.jpg`。公开发布和分发前，请由项目发布者核对图片授权；在 PPT 中出现并不自动等于可以再分发。除此之外， `src/data.js` 是从用户提供的旧版演示迁移的教学文本/拓扑逻辑，公开前仍建议检查文字及场景素材的版权与使用授权，尤其是课堂案例和教师原创表达。仓库中没有以任何方式声称获得课程品牌或教材的授权。
